# A Share Intraday Radar

本地运行的 A 股个股盘中买点雷达，用于跟踪 AI 硬件产业链股票池。

## 启动

推荐在当前 PowerShell / CMD 窗口运行：

```powershell
py start_services.py
```

停止服务：

```powershell
py stop_services.py
```

`start_services.py` 会自动创建 `.venv`、安装/检查 `requirements.txt`，并在当前窗口输出服务地址、PID 状态和日志路径。`start.bat` / `stop.bat` 仍保留为兼容入口，但主要逻辑已经迁移到 Python 脚本。

也可以在虚拟环境中直接使用底层 Python 控制器：

```powershell
.\.venv\Scripts\python.exe radar.py start
.\.venv\Scripts\python.exe radar.py status
.\.venv\Scripts\python.exe radar.py restart
.\.venv\Scripts\python.exe radar.py stop
```

首次运行 `py start_services.py` 会自动创建 `.venv` 并安装依赖。控制器会通过项目身份接口和 PID 文件双重识别进程，避免误停其他 Python 服务。

默认使用 `8030` 端口；如果该端口被无法接管的当前项目旧实例占用，控制器会自动选择后续空闲端口，并在启动信息中打印实际访问地址。`stop.bat` 会根据 PID 文件停止实际端口上的实例。

```powershell
cd D:\codex_project\a_share_intraday_radar
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
py start_services.py
```

默认访问地址：`http://127.0.0.1:8030`

可覆盖端口：

```powershell
$env:WEB_PORT = "8031"
py start_services.py
```

## 功能

- 按行业分组展示股票池。
- 每 60 秒刷新实时行情。
- 计算 MA5/10/20/60、RSI14、量比、均线乖离、20/60 日位置。
- 标记 `可试仓`、`等回踩`、`突破观察`、`二次确认`、`过热不追`、`走弱剔除`。
- 手动刷新和本地缓存兜底。

本工具只做信息监控，不连接券商，不自动下单。

# 核心个股动量与回踩信号系统 (Signals V1.0)

## 一、 信号矩阵总览

| 信号名称 | 场景定义 (Setup) | 核心触发逻辑 | 应对策略 (Action) | 风险度 | 评分 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **可试仓** | 回踩买点 | 多头排列，缩量回撤至重要均线且未过热 | 按计划仓位的 30%-50% 试仓 | 中 | 95 |
| **二次确认** | 二次买点 | 大阳线后企稳于实体半分位上方，再次逼近高点 | 大阳线后横住，再放量转强可小仓跟踪 | 中高 | 85 |
| **突破观察** | 平台突破 | 放量逼近或突破20/60日高点，涨幅健康 | 次日不破突破位再确认 | 中高 | 80 |

| **观察** | 等待确认 | 趋势结构尚未满足任何清晰买点条件 | 未出现清晰买点，继续观察量能修复 | 中 | 40 |

## 二、 信号触发条件详解

### 1. 核心买入层 (Score: 80 - 95)
* **可试仓 (95分)**
    * **量价特征：** 处于多头趋势，从 20 日高点健康回撤 3% - 10%。
    * **均线与量能：** 价格靠近 MA10 或 MA20，且成交量比（Volume Ratio）收敛至 1.25 以下。
    * **风控锚点：** 跌破 MA20 附近或前低（Low20）无条件减仓止损。
* **二次确认 (85分)**
    * **量价特征：** 价格守住前期标志性大阳线的实体半分位之上。
    * **突破前兆：** 价格重新走强，达到大阳线最高价的 98.5% 以上。
    * **后续预期：** 放量彻底站上大阳线最高点后确认突破有效。
* **突破观察 (80分)**
    * **量价特征：** 价格逼近或突破 20 日/60 日平台高点（达到 99.5% 以上）。
    * **动量确认：** 成交量比较 20 日均量明显放大（>= 1.35），且单日涨幅在 1% - 8% 的健康区间。
    * **后续预期：** 次日价格需稳住，不跌回突破位下方。

### 2. 动态观察层 (Score: 40 - 60)
* **等回踩 (60分)**
    * **逻辑：** 股票维持多头排列，但当前位置尴尬，缺乏确切的量价配合买点。
    * **后续预期：** 等待其自然回撤 3% - 8% 并靠近 MA10/MA20 时，信号升格为“可试仓”。
* **观察 (40分)**
    * **逻辑：** 默认兜底状态，趋势结构不够强，暂无交易价值。
    * **后续预期：** 等待价格重新站上 MA20 且量能同步修复。

### 3. 严格风控层 (Score: 5 - 30)
* **过热不追 (30分)**
    * **触发条件 (满足其一即可)：** 单日涨幅 >= 8%、RSI14 >= 78、MA5 乖离率 >= 5%、MA20 乖离率 >= 14%。
    * **应对原则：** 绝对禁止右侧追高，必须等待价格与均线重新收敛。
* **走弱剔除 (5分)**
    * **触发条件 (满足其一即可)：** 绝对价格跌破 MA60（生命线）；或价格跌破 MA20 且伴随单日跌幅 >= 3% 与放量（量比 >= 1.2）。
    * **应对原则：** 系统性趋势破坏，直接移出候选买入池。
