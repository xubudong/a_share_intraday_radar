# 业绩预告预期差打分

## 触发场景

当用户询问以下问题时使用：

- 某只A股最新业绩预告、业绩快报、财报与预期相比如何。
- 半年度业绩预告是否超预期。
- 公告后股票可能怎么走。
- 多只股票中哪些有业绩预告，哪些更值得关注。
- 业绩增长是否来自AI、半导体、PCB、覆铜板、存储、封测等主线兑现。

## 核心原则

不要只看同比增速。必须同时判断：

1. 机构预期差。
2. Q2或最新单季是否加速。
3. 扣非利润质量。
4. 增长来源是否与市场主线一致。
5. 股价是否已经提前反映。
6. 公告是否包含风险提示、澄清、非经常性收益或一次性因素。

默认结论不是“买入/卖出”，而是：

- 大超预期
- 偏超预期
- 符合预期
- 略低于预期
- 明显低于预期
- 无法判断，缺少机构预期或公告数据

## 数据获取顺序

优先使用公告原文，不要凭新闻标题判断。

1. 最新业绩预告、业绩快报、定期报告。
2. 上一季度报告，用于倒推最新单季。
3. 投资者关系活动记录，用于判断订单、产能、产品结构、客户认证、AI或国产替代兑现。
4. 异常波动公告、风险提示公告，用于判断股价是否提前透支、公司是否澄清热门概念。
5. 机构一致预期或券商预测数据。若没有可靠机构预期，必须说明“机构预期缺失”，只能用Q1线性外推、前期调研口径和市场交易预期做代理判断。

## 关键计算

### 半年预告倒推Q2

```text
Q2归母净利润 = H1预告归母净利润 - Q1归母净利润
Q2扣非净利润 = H1预告扣非净利润 - Q1扣非净利润
```

如果只有区间：

```text
Q2低值 = H1低值 - Q1
Q2高值 = H1高值 - Q1
```

### 与Q1线性外推比较

当机构预期缺失时，用Q1线性外推做保守代理：

```text
H1线性外推 = Q1利润 * 2
预告超出幅度 = H1预告中值 / H1线性外推 - 1
```

注意：这不是机构预期，只是临时代理，必须明确标注。

### 扣非质量

```text
扣非占比 = H1扣非净利润 / H1归母净利润
```

判断：

- 扣非接近或高于归母：主业质量好。
- 归母大增但扣非一般：可能有投资收益、公允价值变动、政府补助、资产处置等一次性因素。
- 扣非亏损扩大：财务兑现弱，即使收入、合同额、业务数据好，也不能算业绩超预期。

## 评分规则

总分100分。**符合机构预期为60分及格线**。

### 1. 机构预期差：35分

以公告利润中值对比机构一致预期或主流券商预期。

- 高于预期30%以上：35分
- 高于预期15%-30%：30分
- 高于预期5%-15%：24分
- 基本符合预期，偏差在±5%以内：20分
- 低于预期5%-15%：12分
- 低于预期15%以上：0-8分

若没有可靠机构预期：

- 不得满分。
- 用Q1线性外推和市场前期定价做代理，最高给22分。
- 必须写明“机构预期缺失，以下为代理判断”。

### 2. 单季边际变化：20分

重点看Q2或最新单季是否较Q1继续加速。

- Q2显著高于Q1，且同比/环比均强：20分
- Q2高于Q1但幅度一般：16分
- Q2与Q1大致持平：12分
- Q2低于Q1但仍维持增长：8分
- Q2明显走弱：0-5分

### 3. 扣非与现金含金量：20分

- 扣非与归母同步高增，非经常性损益占比低：20分
- 扣非增长明显，但弱于归母：15分
- 归母高增主要靠投资收益/公允价值变动，扣非一般：8-12分
- 扣非亏损扩大或主营质量弱：0-6分

### 4. 主线兑现纯度：15分

判断利润增长是否直接来自市场正在交易的主线。

- 公告或调研明确验证订单、客户认证、产能释放、AI/算力/存储/封测/PCB等主线收入利润：15分
- 与主线相关，但更多是周期涨价或间接受益：10-12分
- 公司澄清未进入热门主线、尚未形成收入：4-8分
- 只是题材联想，没有业绩兑现：0-4分

### 5. 股价预期与兑现风险：10分

这是扣分项思维，判断公告后交易难度。

- 股价未明显提前涨，预期低：10分
- 有上涨但未极端，承接仍可观察：6-8分
- 公告前已大涨、多次异动，利好兑现风险高：2-5分
- 一字板/连续大涨后披露，交易拥挤严重：0-2分

## 分数解释

```text
85-100：大超预期，重点关注，但仍看开盘承接。
70-84：偏超预期，有研究价值。
60-69：符合预期，及格，但不构成强催化。
45-59：略低于预期或质量一般，谨慎。
0-44：明显低于预期、利润质量差或题材未兑现。
```

## 常见判断模板

### 生益科技类型

业绩强，扣非强，AI高速材料或PCB链订单兑现真实，但股价已提前上涨。

```text
结论：符合偏超预期到偏超预期。
重点：质量高，确定性强，但短线防兑现。
```

### 金安国纪类型

同比很炸，但增长来自通用覆铜板周期涨价，公司澄清AI高端应用未形成收入。

```text
结论：业绩大超预期，AI纯度打折。
重点：周期弹性强，但不能按AI核心材料满分定价。
```

### 通富微电类型

归母高增，扣非也增长，但投资收益显著增厚归母。

```text
结论：偏超预期，但利润质量需打折。
重点：主营改善真实，归母爆发不能全按主营兑现理解。
```

### 科大讯飞类型

收入、合同、回款、AI业务数据有亮点，但扣非亏损扩大。

```text
结论：业务逻辑有亮点，财务兑现不及格或仅勉强。
重点：不是业绩兑现票，更偏长期AI应用逻辑。
```

### 有研新材类型

热门材料题材、国产替代、异动公告多，但缺少业绩预告验证。

```text
结论：题材异动，无法按业绩预告打高分。
重点：等利润、订单或客户验证。
```

## 风险提示

- 机构预期可能滞后，必须标注数据日期。
- 没有机构预期时，不要伪装成“市场一致预期”。
- 同比高增可能来自低基数。
- 归母高增要拆扣非和非经常性损益。
- 题材纯度要以公告和调研为准，公司澄清优先级高于市场传闻。
- 股票短线反应取决于预期差和筹码位置，不等于业绩好就上涨。
