# 股票池行业三级分类迁移草案

## 目的

本文档把当前 `config/stock_pool.yaml` 中的 123 个分组映射到统一的三级行业结构：

`一级大板块 -> 二级产业环节 -> 三级细分赛道`

这是一份分类迁移草案，不直接代表个股已经通过业务证据核验。后续个股审计仍需依据年报、公告、收入结构、订单、客户和量产情况，逐只执行“保留、改组、调梯队、待验证、剔除”。

## 规则

- 一级板块用于观察大行业整体强弱。
- 二级行业用于观察产业链环节整体强弱。
- 三级赛道用于盘中精确筛选、涨跌统计、快照和星标。
- “红利、先进封装、国产替代、AI应用、固态电池、CPO”等是横向主题标签，不代替主行业。
- 标记为“拆分”的旧分组不能整体迁移，必须按个股主营分别归类。
- 同一股票只能有一个主行业，但可以拥有多个主题标签。

## 八、实施前必须解决的系统问题

1. 当前 `StockConfig` 只有 `group/groups`，没有一级、二级、三级和标签字段。
2. 重复股票的第一次出现位置决定主分组，配置顺序会影响主行业。
3. 同一股票跨组时，梯队取最小值，无法表达“主行业T1、主题方向T3”。
4. 需要增加独立的 `primary_industry`、三级行业路径和 `tags`，并让三级层级都支持筛选、统计、快照与星标。
5. 迁移时必须兼容已有板块星标和笔记，否则改名后用户状态会丢失。
