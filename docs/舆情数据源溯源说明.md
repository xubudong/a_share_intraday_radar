## 逐源说明

### 1. WallstreetCN 全球快讯

- 项目 source：`wallstreetcn_global`
- 采集函数：`fetch_wallstreetcn_lives("global-channel", ...)`
- 浏览器页面：
  - https://wallstreetcn.com/live/global
  - https://wallstreetcn.com/live
- JSON 接口：
  - `https://api-prod.wallstreetcn.com/apiv1/content/lives?channel=global-channel&client=pc&limit=50`
- 翻页参数：
  - `cursor`
- 项目取用字段：
  - `title`
  - `content`
  - `display_time` -> `published_at`
  - `symbols`
- 项目处理：
  - 按目标日期过滤 `display_time`
  - 按 `id` 去重
  - 清洗 HTML
  - 转成新闻时间线条目
  - 用股票池对标题和正文做自动命中

### 2. WallstreetCN A 股快讯

- 项目 source：`wallstreetcn_a_stock`
- 采集函数：`fetch_wallstreetcn_lives("a-stock-channel", ...)`
- 浏览器页面：
  - https://wallstreetcn.com/live/a-stock
  - https://wallstreetcn.com/live
- JSON 接口：
  - `https://api-prod.wallstreetcn.com/apiv1/content/lives?channel=a-stock-channel&client=pc&limit=50`
- 项目取用字段和处理方式：
  - 与 `wallstreetcn_global` 一致。
- 备注：
  - `symbols` 多数情况下可能为空；项目不依赖它做股票映射。

  - `os=web`
  - `sv=8.4.6`
  - `sign=9f8797a1f4de66c2370f7a03990d2737`
- 项目取用字段：
  - `market_degree`
  - `up_ratio`
  - `profit_ratio`
  - `shsz_balance`

### 4. levistock 今日风口

- 项目 source：`levistock_market_wind`
- 采集函数：`levistock.market_wind_cls()`
- 上游来源：财联社
- 浏览器页面：
  - https://www.cls.cn/
  - 财联社首页中有“题材推荐 / 今日风口”区域，可人工核对板块名称和驱动文字。
- JSON 接口：
  - `https://api3.cls.cn/v2/todayTuyere`
- 请求特点：
  - 移动端风格接口。
  - 需要基础参数和 `sign`。
  - Header 使用 `User-Agent: okhttp/4.9.0`，`Host: api3.cls.cn`。
- 基础参数：
  - `app=cailianpress`
  - `sv=8.7.4`
  - `os=android`
  - `mb=Xiaomi-2206123SC`
  - `ov=32`
  - `channel=8`
  - `motif=0`
  - `province_code=3205`
  - `token=`
  - `uid=`
- sign 规则：
  - 参数按 key 字母序排序
  - 拼成 `k=v&k=v`
  - 先 SHA1，再 MD5
- 上游原始字段：
  - `plate_code`
  - `title`
  - `interpret`
- levistock 映射后字段：
  - `plate_code`
  - `plate_name = title`
  - `catalyst = interpret`
- 项目展示：
  - 显示为 `plate_name：catalyst`
  - 同时用股票池匹配 `plate_name`、`catalyst` 和原始 JSON 文本。

### 6. levistock 涨停天梯

- 项目 source：`levistock_zttt`
- 采集函数：`levistock.get_zttt()`
- 上游来源：开盘啦/复盘啦
- 浏览器页面：
  - https://www.kaipanla.com/
  - 更适合用开盘啦 App 或相关复盘页面核对“涨停天梯”。
- 今日接口：
  - `https://apphwshhq.kaipanhong.com/w1/api/index.php`
- 历史接口：
  - `https://apphis.kaipanhong.com/w1/api/index.php`
- 请求参数：
  - `a=GetZhangTingTianTi`
  - `c=FuPanLa`
  - `Date=YYYY-MM-DD`
  - 另带 App 基础参数，例如 `PhoneOSNew`、`DeviceID`、`VerSion`、`apiv`。
- 原始结构：
  - `StockList`
- `StockList` 单条数组含义：
  - `[0]` 股票代码
  - `[1]` 股票名称
  - `[2]` 连板数
  - `[3]` 涨停时间戳
  - `[4]` 所属板块代码
  - `[5]` 所属板块名称/原因
  - `[6]` 是否大单一字
  - `[7]` 是否有人气
  - `[8]` 板块涨停股数量
  - `[9]` 个股成交额
  - `[10]` 板块成交额
- 项目展示：
  - 展示 `代码 名称 N板 原因/板块`
  - 原始 `StockList` 保留在 `payload.json`。

## 本项目落盘与展示关系

采集后，完整原始 payload 写入：

```text
data/sentiment/YYYY-MM-DD/payload.json
```

前端 `/market` 不直接读取文件，而是请求：

```text
GET /api/sentiment?date=YYYY-MM-DD
```

后端读取 `payload.json` 后派生：

- `timeline`：新闻时间线
- `market_sections`：市场情绪、今日风口、板块热度、涨停天梯、涨停原因、AI主题摘要、市场情绪序列
- `source_summary`：每个源的状态、条数、耗时、错误信息
- `summary`：展示统计

人工重点标记单独保存：

```text
data/sentiment_marks.json
```

股票池自动命中运行时基于：

```text
config/stock_pool.yaml
```

不会写回 `payload.json`。

## 溯源注意事项

- 华尔街见闻页面和 JSON 接口较适合直接浏览器核对。
- 财联社部分接口需要签名参数；页面核对更适合打开 https://www.cls.cn/ 或 https://www.cls.cn/telegraph，再找对应区域。
- 开盘啦涨停天梯更偏 App/移动端接口，网页官网主要用于入口和 App 下载，未必能直接看到同一份结构化表。
- zzshare 使用自在量化 API 封装，浏览器核对优先看 https://quant.zizizaizai.com/；接口路径可用于开发侧追踪，但不一定适合裸浏览器直接打开。
- 外部页面会实时变化；本项目复盘时以本地 `payload.json` 为当天快照准绳。
